About

A fan-made viewer for the monsters of Monster Hunter Generations Ultimate, with the game's own models, textures and motion lists. Not affiliated with, endorsed by, or supported by Capcom.

Game content

Monster Hunter Generations Ultimate and all of its models, textures, animations and data tables are © CAPCOM CO., LTD. All rights reserved. Every asset here was extracted from a personally owned copy of the game and is shown for reference only.

What you are looking at

Each monster is its own archive in the game: one model, its maps, a part-visibility table and several motion lists. The clips carry no names in the game data, only numbers, so they are listed as the game stores them. The part rows come from the game's own visibility groups.

Tools used to build this

  • RevilLib / RevilToolset — by PredatorCZ (Lukas Cone) Unpacked the .arc archives and converted MT Framework .mod meshes to glTF, .tex textures to DDS, .lmt motion lists to animation, and the part tables to XML.
  • hactool Unpacked the game's romfs and executable from the cartridge image.
  • three.js Renders the scene, with GLTFLoader, OrbitControls and SkeletonUtils.
  • Pillow Converted the extracted textures during the build.
  • MHGU-Modding wiki — by RTHKKona and contributors, ported from GReinoso96 and Aradi147's XXModding Documented the model and texture extraction route this project followed.

Assets

Monster icons, UI textures and the MHFU font are shared with the sibling MHGU fan apps listed under Other MHGU Apps. Monster names come from the game's own carve tables and from the MHGU Monster Info project.

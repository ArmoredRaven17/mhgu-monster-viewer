## 1. The event system (shared walker, his table)

set by EMC op a3 (0, n) and taken at the action's start (0x6cb14). A row is 0x2c bytes: +0 type, +4 motion, +8 kind, +0xc f0, +0x10
f1, +0x1c.. the float args. Kind 1 = the frame crossing of f0 (0xb0968 mode 0 = 0x72714 mode 0, the viewer's pass001). Types > 6
go to his vt+0x480 0x10ab6c0 (table 0x10ab708). Rows by action and motion: `<archive>\neset\rows087.json` (seq087.txt x
emcpair087.txt, limited to what the walk reaches). shells.js carries one `act087` row per (action, motion, selector), deduplicated
when every selector of the action gives the same rows.

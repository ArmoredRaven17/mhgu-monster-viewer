## The arms (READ) — who "the enemy" is in most rows

- `uEm084_00`'s ctor builds two `uEmOstgaloaArm` objects **inside the body**: at **body+0xcc00** and
  **body+0x19750** (`bl 0x107b29c` at 0x1064af8 / 0x1064b04). Class `uEmOstgaloaArm`: DTI `0x184a8b8`, size 0xcb50,
  **vtable `0x17f6498`** (ctor 0x107b29c: GOT 0x183f8b8 + 8), action main **`0x107d680`** (+0x1f4).
- `0x107cf9c(arm, body, kind, …)` sets **`[arm+0xcadc]` = the body** and **`[arm+0xcae0]` = kind**: called with
  kind **1** for body+0xcc00 (0x1064e68 / 0x1064e8c) and kind **2** for body+0x19750 (0x1064efc / 0x1064f1c).
- **Kind 1 = LEFT, kind 2 = RIGHT.** The arm's resource load (vtable +0x148 = `0x107ba5c`) picks by kind: model
  res **0x8370 / 0x8371**, and from table `0x16a2bd8` (7 words per kind) motion lists **0x8374 / 0x8376 / 0x8378**
  (kind 1) or **0x8375 / 0x8377 / 0x8379** (kind 2) into motion slots **0 / 2 / 3** (`0x954438(arm, res, 0 / 2 / 3)`
  at 0x107bb50 / 0x107bb9c / 0x107bbe8). The resource table `0x159daa0` (`0x152530`: 8-byte entries
  {path hash, type hash}) gives hashes that equal `~crc32(path)` of `enemy\em084\em084_00\mod\em084_00_left` /
  `…_right` and `enemy\em084\em084_00\mot\em084_00_l_0 / l_2 / l_3` / `r_0 / r_2 / r_3` (the hash scheme checked on
  a known entry: res 0x8abb = `shell\em\em084_00_shell02\em084_00_02`). **So an arm's motion `0x2NN` plays the
  viewer's list `l_2` (left) or `r_2` (right), and `0x0NN` plays `l_0` / `r_0`.**
- The arms read the **body's** action tune: every arm gate is `0x6f618([arm+0xcadc], i)` (`ldr r0,[r5]` with
  r5 = arm+0xcadc left by the pre-indexed `ldr r0,[r5,r0]!` — trap 16), i.e. `em084_00_actiontune.fup`.
